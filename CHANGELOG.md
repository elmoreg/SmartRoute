# Changelog

## 0.1.0 — Initial release

- FastAPI + SQLite backend
- Two route optimization modes: by distance (Google Directions waypoint optimization) and by sector (group by comuna/barrio)
- Frontend with embedded Google Maps, Places autocomplete, geolocation origin
- Address input via manual entry, bulk paste, or map click
- Route history persisted in SQLite
- Unit tests for geocoding parsing and optimizer logic
